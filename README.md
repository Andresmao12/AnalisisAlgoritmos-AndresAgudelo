# Análisis de Algoritmos

Repositorio académico correspondiente al curso **Análisis de Algoritmos**. Este repositorio será utilizado durante el semestre para almacenar, organizar y documentar las diferentes actividades prácticas desarrolladas en el curso.

El objetivo principal es mantener en un solo lugar los ejercicios realizados durante las sesiones de clase, los informes de laboratorio y las herramientas utilizadas para analizar y comparar el comportamiento de diferentes algoritmos.

Además del desarrollo de los ejercicios, este repositorio permitirá practicar el uso de **Git y GitHub** como herramientas de control de versiones, manteniendo un historial organizado de los cambios realizados durante el semestre.

## Objetivos del repositorio

Este repositorio tiene como objetivos:

- Organizar las actividades, laboratorios y ejercicios desarrollados durante el curso.
- Implementar y analizar diferentes algoritmos y estructuras de datos.
- Comparar el rendimiento de diferentes soluciones mediante mediciones de tiempo.
- Utilizar herramientas de benchmarking para estudiar la eficiencia de los algoritmos.
- Implementar buenas practicas de control de versiones utilizando Git.
- Documentar adecuadamente los experimentos, resultados y conclusiones obtenidas durante los laboratorios.

## Estructura del repositorio

El proyecto se encuentra organizado en diferentes carpetas, cada una destinada a un propósito específico:

- `laboratorios/`: contiene los cinco informes de laboratorio evaluativos realizados durante el semestre. Cada laboratorio tendrá su propia carpeta con el código, documentación, resultados y demás archivos necesarios para su desarrollo.

- `ejercicios-clase/`: contiene los ejercicios, ejemplos y prácticas desarrollados durante las sesiones de clase. Aquí se almacenarán las actividades que permitan reforzar los conceptos vistos en el curso.

- `benchmarks/`: contiene los scripts y herramientas utilizados para realizar mediciones de rendimiento. Estos recursos permitirán comparar tiempos de ejecución y analizar experimentalmente la eficiencia de diferentes algoritmos.

- `README.md`: contiene la información general del repositorio, su propósito y la descripción de su estructura.

- `.gitignore`: contiene los archivos y carpetas que Git debe ignorar para evitar subir información innecesaria o archivos generados automáticamente.

## Temas del curso

A lo largo del semestre, el repositorio servirá como soporte para estudiar y aplicar los principales conceptos del **análisis y diseño de algoritmos**, desde los fundamentos de programación hasta estrategias avanzadas de resolución de problemas.

Entre los temas que se abordarán se encuentran:

- Sintaxis de Python.
- Algoritmos como tecnología.
- Análisis de algoritmos y estrategia de divide y vencerás.
- Notación `O`, `Θ` y `Ω`.
- Resolución de recurrencias.
- Subarreglo máximo y algoritmo de Strassen.
- Síntesis del paradigma de divide y vencerás.
- Heaps y Heapsort.
- Quicksort determinista y aleatorizado.
- Counting sort, Radix sort y Bucket sort.
- Medianas, selección y estructuras elementales.
- Tablas hash.
- Fundamentos de programación dinámica.
- Elementos de programación dinámica y subsecuencia común más larga.
- Estrategia voraz.
- Síntesis de los conceptos trabajados durante el semestre.

Los ejercicios, prácticas y laboratorios permitirán aplicar estos conceptos mediante implementaciones en código, análisis de algoritmos y comparación de diferentes estrategias para resolver problemas computacionales.

## Herramientas y tecnologías

Para el desarrollo de las actividades del curso se utilizarán principalmente:

- **Python** para la implementación de algoritmos y ejercicios.
- **TypeScript** para las actividades que requieran este lenguaje.
- **Git** para el control de versiones del código.
- **GitHub** para almacenar y sincronizar el repositorio remoto.
- Herramientas de medición y graficación para analizar el rendimiento de los algoritmos.


# Resumen

## Primera sesion

En esta sesión se estudiaron los fundamentos del **control de versiones** utilizando **Git y GitHub**. Se aprendió a crear y organizar un repositorio, registrar cambios mediante commits y mantener un historial del proyecto.

También se trabajaron conceptos como:

- `git init` para inicializar un repositorio.
- `.gitignore` para excluir archivos que no deben ser versionados.
- `README.md` para documentar el proyecto.
- `git add` y `git commit` para registrar cambios.
- `git log` y `git diff` para consultar el historial y revisar modificaciones.
- Repositorios remotos y sincronización mediante `push`, `pull`, `fetch` y `clone`.
- Ramas (`branch`) y `merge` para trabajar con cambios en paralelo.
- Conflictos de fusión y su resolución.

### Uso habitual

```bash
git pull
git status
git add .
git commit -m "Descripción del cambio"
git push
```
